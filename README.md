# Guardias

Calendario de guardias (cada 5 días), preguardias, servicio y días libres. Funciona como PWA instalable.

Página: https://julio22b.github.io/guardias/

Los datos (fecha de guardia, feriados marcados) se guardan en localStorage del navegador.

Al cambiar archivos, sube el número de `CACHE` en `sw.js`.
